# Trafik Lambasına Yazılan Aşk Mektupları

> **Resmi Uyarı:** Bu depo, kırmızı ışıkta beklerken oluşan duygusal çöküşü bilimsel olarak ölçmek ve lambaya resmi mektup yazmak için kurulmuştur. Şaka değildir. Şakaydı. Hayır değildi.

## Bu Proje Ne İşe Yarar?

Hiçbir işe yaramaz. Ama **çok ciddi** bir hiçbir işe yaramazlıktır.

`mektup.py` çalıştığında:
1. Rastgele bir kavşak seçer (uydurma)
2. Lambanın karakter analizini yapar (kırmızı = soğuk, yeşil = umut taciri)
3. Resmi bir aşk / kınama / özür mektubu basar
4. Mektubu asla göndermez çünkü lambanın postası yoktur

## Kurulum

```bash
python3 mektup.py
```

Bağımlılık: Python 3 ve biraz sabır. Yeşil ışık beklemeye benzer bir sabır.

## Örnek Çıktı

Program kendi kendine konuşur. Siz dinlersiniz. Lamba dinlemez.
